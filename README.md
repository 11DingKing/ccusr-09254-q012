# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 活动主办方责任链

联合实训中一个活动可能由学院、企业和第三方共同负责。`/api/activities/{activity_id}` 下提供责任链接口：

- **责任配置**：`POST /grants` 建立责任角色、授权范围（可更正的字段类别）和有效区间；`GET /chain?at=` 查询任意时刻的当时责任链；`PUT /shared-fields` 配置多方共同字段及会签角色。
- **授权判定**：`POST /authorize` 按事件业务时间匹配当时责任链，判定参与方能否更正字段（直接持有或经委托获得）。
- **事件更正与会签**：`POST /corrections` 提交更正，越权直接拒绝（403）；共同字段进入会签，`POST /corrections/{id}/countersign` 由其他责任方全部同意才生效。
- **责任转移**：`POST /transfers` 在生效时刻截断当前授权并开启新授权，不追溯改写旧授权的历史区间；基于版本号做乐观并发控制，并发转移只有一方成功（409）。
- **委托授权**：`POST /delegations` 支持责任方在区间内委托他人行使更正权，同一时刻生效的委托关系成环即拒绝（循环授权）。
- **紧急操作**：紧急更正先生效，须在补审期限内由当时责任链上的其他责任方 `POST /corrections/{id}/review` 补审，逾期不可补审且可经 `GET /corrections?overdue_only=true&as_of=` 查询。
- **审计查询**：`GET /audit` 汇总授权、委托、共同字段配置与更正的全部审计记录，支持按动作、操作人和聚合类型过滤。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

```bash
python3 -m pytest -q
```

## 编译检查

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询，以及责任链的循环授权、并发转移、跨日生效和越权拒绝；运行过程中不需要单独的数据库或网络服务。
